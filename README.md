# Medications Tracker~~~~

Современное мобильное приложение на Android для удобного и надежного отслеживания приема лекарств,
витаминов и БАДов. Приложение построено на основе современных подходов к разработке под Android с
использованием декларативного интерфейса **Jetpack Compose**, принципов **Clean Architecture** и
архитектурного паттерна **MVVM**.

---

## 🌟 Ключевые возможности (Features)

* 📅 **Планирование курсов приема**: добавление лекарств с указанием дозировки (в мг), даты начала,
  даты окончания курса и гибкого времени приема.
* 🔔 **Умные напоминания**: интеграция с системным планировщиком **AlarmManager** и уведомлениями,
  что гарантирует точную доставку напоминаний даже в фоновом режиме работы устройства.
* 📝 **Интерактивный журнал приема**: отслеживание запланированных приемов лекарств (возможность
  отметить прием как выполненный или пропущенный) с возможностью добавления текстовых заметок.
* 💾 **Оффлайн-режим (Offline First)**: кэширование и хранение всех данных о лекарствах, курсах и
  логах приемов локально с помощью **Room Database**.
* 🎨 **Современный дизайн**: премиальный интерфейс, соответствующий гайдлайнам **Material Design 3**,
  с настраиваемыми UI-компонентами (диалоги выбора даты/времени, кастомные кнопки) и плавной
  анимацией.

---

## 🛠 Технологический стек (Tech Stack)

При разработке приложения были использованы самые актуальные библиотеки и фреймворки
Android-разработки:

* **Язык**: [Kotlin](https://kotlinlang.org/) (с использованием Kotlin Coroutines и Flow для
  реактивного программирования)
* **UI-фреймворк**: [Jetpack Compose](https://developer.android.com/compose) (декларативный UI с
  поддержкой Material 3)
* **Архитектурный шаблон**: MVVM (Model-View-ViewModel) + Clean Architecture
* **Внедрение зависимостей (DI)
  **: [Dagger Hilt](https://developer.android.com/training/dependency-injection/hilt-android)
* **Локальная база данных
  **: [Room Database](https://developer.android.com/training/data-storage/room)
* **Дата и время**: [kotlinx-datetime](https://github.com/Kotlin/kotlinx-datetime) (современная
  библиотека для работы со временем в Kotlin)
* **Системные уведомления
  **: [AlarmManager](https://developer.android.com/about/versions/14/changes/schedule-exact-alarms) &
  BroadcastReceiver

## 📂 Структура проекта (Project Structure)

Проект разделен на логические слои и модули. Основной модуль приложения (`tracker2`) спроектирован
по слоям Clean Architecture внутри пакета `com.galeria.medtracker2`:

```
com.galeria.medtracker2/
│
├── core/                         # Ядро приложения и разделяемые компоненты
│   ├── database/                 # Room Database (Entity, DAO, Database)
│   ├── notifications1/           # Реализация уведомлений и AlarmManager
│   ├── ui/                       # Дизайн-система (Colors, Typography, Theme, кастомные UI-компоненты)
│   └── utils/                    # Вспомогательные утилиты (DateTimeUtils, ResultState)
│
├── data/                         # Слой данных (Data Layer)
│   ├── mappers/                  # Мапперы между DB Entity и Domain моделями
│   └── repository/               # Реализация репозиториев (Repository Implementations)
│
├── domain/                       # Бизнес-логика (Domain Layer - чистый Kotlin)
│   ├── model/                    # Бизнес-модели данных
│   ├── repository/               # Интерфейсы репозиториев
│   └── use_case/                 # Сценарии использования (Use Cases)
│
├── feature/                      # Модульные фичи приложения
│   ├── auth/                     # Модуль авторизации (Вход, Регистрация, Восстановление пароля)
│   └── tracker/                  # Модуль трекера (Добавление лекарств, Расписание, Журнал приемов)
│
└── navigation/                   # Навигация (Compose Navigation, AppNavHost, AppRoutes)
```

## 🚀 Настройка и запуск (Setup)

Для сборки и запуска проекта вам понадобятся:

1. **Android Studio** (рекомендуется Ladybug / Koala или более новая версия).
2. **Android SDK** (минимальный SDK — 28, целевой/компиляционный SDK — 36).
3. Установленная Java Development Kit (**JDK 17**).

### Шаги для запуска:

1. **Клонируйте репозиторий**:
   ```bash
   git clone <URL_репозитория>
   ```
2. **Настройте Firebase**:
    * Создайте проект на [Firebase Console](https://console.firebase.google.com/).
    * Добавьте Android-приложение с ID пакета `com.galeria.medtracker2`.
    * Скачайте файл настроек `google-services.json` и поместите его в папку `tracker2/` (и
      `medicationstracker/` при необходимости).
3. **Откройте проект в Android Studio** и дождитесь окончания синхронизации Gradle.
4. **Соберите и запустите приложение** на эмуляторе или физическом устройстве.
